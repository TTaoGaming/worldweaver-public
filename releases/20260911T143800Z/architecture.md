# Gleipnir and the Grimoire

The compound system combines a human operator, model carriers, deterministic procedures, durable memory, source receipts, and independent verification. A session can help reconstruct the context without becoming the whole system or inheriting its access.

Gleipnir binds mnemonic language to typed invariants, executable checks, provenance, and held-out tests. Read [the six preserved formulations and two WIP forms](formulations.json), [mathematical map](mathematics.json), [semantic decoder](semantic-tokens.json), and [compound actor model](sigrun-architecture.json). Their source status remains explicit; formulas and prose do not prove that runtime controls exist.

The Grimoire is an eight-room reading index: germline; semantic and mathematical decoding; memory; heritage; dated world state; skills and constraints; restoration; receipts. Each node binds up to eight files or child nodes by exact SHA-256. This release implements a finite static unfolding index, not a self-replicating program or a proved mathematical quine.
